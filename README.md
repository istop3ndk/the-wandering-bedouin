# The Wandering Bedouin

A desert action roguelike: auto-firing skills, a passive tree, rifts, trials, idols, and a horde that doesn't let you stand still. Dying is part of it.

## Download and play (Windows)

1. Open **[Releases](../../releases)** → **The Wandering Bedouin 1.0.0** → download `The Wandering Bedouin 1.0.0 (Windows).zip`.
2. Extract the zip anywhere.
3. Run **The Wandering Bedouin.exe**.

Windows may say *"Windows protected your PC"* the first time, because the game isn't code-signed. Click **More info → Run anyway**.

Needs 64-bit Windows and a graphics card with Vulkan support. Your progress saves automatically.
